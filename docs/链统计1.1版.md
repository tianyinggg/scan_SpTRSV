# 链统计 1.1 版

本文档记录旧版链统计实现逻辑。该版本不是当前使用的“严格单前驱链”口径，而是更早期的“唯一最深前驱”口径。

## 1. 基本输入

输入为稀疏矩阵 `A`，按下三角依赖分析。

对每一行 `i`，构造前驱集合：

`pred[i] = { j | A[i, j] != 0 且 j < i }`

注意：

- 不包含对角元 `A[i, i]`
- 只统计严格下三角依赖 `j < i`

## 2. 层级定义

对每一行计算依赖层级 `level[i]`：

- 若 `pred[i]` 为空，则 `level[i] = 1`
- 否则：
  `level[i] = 1 + max(level[p] for p in pred[i])`

这个定义刻画的是静态依赖图中的最长前驱路径深度。

## 3. 扫描父节点选择

旧版实现不是按“前驱数是否等于 1”来建链，而是先在所有前驱中选择“最深前驱”。

对某一行 `i`：

1. 找到 `pred[i]` 中层级最大的前驱深度 `max_pred_level`
2. 收集所有达到该最大深度的前驱，记为 `max_preds`
3. 如果 `len(max_preds) == 1`，则：
   `scan_parent[i] = max_preds[0]`
4. 如果 `len(max_preds) > 1`，则：
   `scan_parent[i] = -1`
   并把该行记为 `invalid_multi_unresolved_row`

因此，这一版的关键规则是：

- 不是要求“前驱只有 1 个”
- 而是要求“最深前驱唯一”

## 4. 可扫描行定义

若某一行满足：

`scan_parent[i] != -1`

则它被记为可扫描行 `eligible row`。

如果某行没有前驱，或者存在多个并列最深前驱导致无法唯一选父节点，则它不会作为可扫描子图中的内部节点。

## 5. 链提取逻辑

基于 `scan_parent` 可构造一个有向森林：

- 边方向为 `scan_parent[i] -> i`
- 所有 `scan_parent[i] != -1` 的节点构成可扫描子图

起点定义为：

- 某个节点 `i` 是可扫描行
- 且它的父节点不在可扫描子图中

从这些起点出发，沿着 `scan_parent` / `children` 关系向下遍历。

旧版链提取不是“线性段截断”口径，而是：

- 在森林中按根到叶路径统计链
- 如果某个节点出现分叉，则会形成多条根到叶路径
- 因此链数可能大于起点数

## 6. 旧版统计关注的核心问题

这一版主要回答：

- 矩阵的最长依赖深度有多深？
- 每行是否存在唯一的“主依赖前驱”？
- 基于唯一最深前驱规则，可以形成多少条扫描链？

它更接近“唯一主依赖链”的提取，而不是现在的“严格单前驱链”。

## 7. 旧版典型字段

旧版 CSV 中常见字段包括：

- `matrix_name`
- `n_rows`
- `nnz`
- `max_level`
- `critical_depth_ratio`
- `deep_row_ratio_5pct`
- `deep_row_ratio_10pct`
- `scan_chain_count`
- `scan_eligible_rows`
- `scan_eligible_row_ratio`
- `max_scan_chain_length`
- `avg_scan_chain_length`
- `scan_chain_len_ge_32`
- `scan_chain_len_ge_64`
- `invalid_multi_unresolved_rows`
- `invalid_multi_unresolved_ratio`

这些字段反映的是：

- 依赖深度
- 唯一最深前驱可判定比例
- 根到叶扫描链统计
- 最深前驱并列冲突情况

## 8. 与当前严格单前驱版的区别

当前严格单前驱版与 1.1 版的区别非常明显：

1. 1.1 版按“唯一最深前驱”选父节点
   当前版按“前驱数是否恰好为 1”定义严格单前驱

2. 1.1 版依赖 `level`
   当前版不需要 `level`

3. 1.1 版允许某行有多个前驱，只要最深前驱唯一
   当前版只允许链身节点有且仅有 1 个前驱

4. 1.1 版链统计偏向“主依赖森林中的根到叶路径”
   当前版链统计偏向“边界链头出发的严格线性段”

5. 1.1 版会显式统计 `invalid_multi_unresolved_rows`
   当前版更关注 `strict_multi_pred_rows` 和 `strict_branch_rows`

## 9. 适用理解

可以把 1.1 版理解为：

- 一种“主依赖抽取”的早期统计口径
- 它适合粗略衡量矩阵里是否存在清晰的主依赖链
- 但它不等价于严格单前驱 scan 链

因此，1.1 版更适合作为历史版本或对照版本保留。
